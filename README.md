## 🚀 How to Run Locally

### Method 1: Double Click
Double click `OPEN_ASIFGKBD_WEBSITE.bat` in the root folder, or open `asifgkbd_website/index.html` directly in any web browser (Chrome, Edge, Firefox, Brave, Safari).

### Method 2: Local HTTP Server (Python)
If you want to host it on your local network or test with an HTTP server:
```bash
cd asifgkbd_website
python -m http.server 8080
```
Then visit: `http://localhost:8080` in your browser.

## 🌍 How to Connect your Domain `ASIFGKBD.com`

### Option A: Free GitHub Pages (Recommended)
1. Push this folder to a GitHub repository named `asifgkbd.github.io` (or any repo).
2. Go to **Repository Settings** > **Pages**.
3. Under **Custom domain**, enter: `ASIFGKBD.com`
4. In your Domain Registrar (Namecheap, GoDaddy, Cloudflare, or BTCL/Dhaka Web Hosts):
   - Add an **A Record**:
     - `@` points to: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - Add a **CNAME Record**:
     - `www` points to: `yourusername.github.io`

### Option B: Cloudflare Pages / Vercel (Fastest with Free SSL)
1. Drag and drop the `asifgkbd_website` folder into **Cloudflare Pages** or **Vercel**.
2. Add custom domain `ASIFGKBD.com`.
3. Cloudflare/Vercel will automatically configure free global CDN, DDoS protection, and SSL encryption!
