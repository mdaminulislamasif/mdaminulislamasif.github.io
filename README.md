## 🚀 How to Run Locally

### Method 1: Double Click
Double click `OPEN_WEBSITE.bat` or `OPEN_ASIFGKBD_WEBSITE.bat` in the root folder, or open `asifgkbd_website/index.html` directly in any web browser (Chrome, Edge, Firefox, Brave, Safari).

### Method 2: Local HTTP Server (Python)
If you want to host it on your local network or test with an HTTP server:
```bash
cd asifgkbd_website
python server.py
```
Then visit: `http://localhost:5000` in your browser.
